# 已确认的制作流程

项目目录是入口。一个项目内可以顺着七个阶段完成整片，也可以只做一张图片。页面和导演指令读写同一批项目与镜头记录。

| 阶段 | 工作区 | 核心交付物 |
|---|---|---|
| 0 | 项目目录。隔离剧本、素材与作业，需要时授权固定版本引用，或复制为另一项目的独立素材。 | 项目简报、素材库与跨项目授权。 |
| 1 | 从创作意图生成各章节的大纲，逐章调整标题和节拍。 | 可编辑、有稳定章节标识的大纲。 |
| 2 | 从大纲写全本或分章写剧本，保存场景、动作、对白、声音和导演意图。 | 章节剧本及镜头表。 |
| 3 | 由镜头打开图片工作室，或从目录直接入场。文字、底图、参考图可以组合，局部修改另带用户选区。 | 可独立下载、入库、分享和绑定镜头的图片。 |
| 4 | 整本剧本映射到无限画布，可平移、缩放、整理节点，按章或镜头进入编辑。 | 全剧 Map、采用的画面与跨章承接关系。 |
| 5 | 分章试拍或从 Map 选择镜头。区分首帧与外观参考，选定版本后再入剪。 | 真实生成的视频条次与叙事顺序。 |
| 6 | 跨章组接，按镜头调整顺序、入点和时长，导出经过解码校验的文件。 | 固定剪辑修订、MP4 与逐镜来源记录。 |

**验收片段**。从只有一份简报的新项目开始，两章均有不同的文字、插图和动态镜头。Agent 把两段组接成可播放的文件。另一条路径从独立文字生图开始，在这张图上进行选区编辑，导出结果而项目中仍没有剧本或时间线。修改镜头顺序后再次导出，新文件的内容和帧数应随修改变化。

**成片质量**。初版应报告真实模型、尺寸、帧率、有效运动、编辑保护区及生成时间。更高要求如跟踪运动遮罩、商业客户审片、多轨混音和多人权限需要单独验收。在现阶段，个人工作台对实际开放的能力提供操作入口。
