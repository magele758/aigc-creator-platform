# 实机验收 · 2026-11-20

在本机 Web 服务的正常 HTTP 入口提交用户委托，使用 `ppeng-agent-core/agent-loop` 和已配置的文字模型，图片和视频在 RTX 4090 D（24 GB）运行。两条创作路径均实际生成文件并独立解码。验收不使用评审原型中的样片。

## 导演自建项目并交付短片

《红舟过雨》由两章组成，分别为「桥影入光」和「金反射入」。导演实际调用了项目大纲、章节剧本和镜头制作工具。项目中保存了两份关键帧、两份动态镜头、跨章关系、剪辑序列和成片。逐镜核对了来源、动态变化、输出时间和次序。[观看标准版 MP4](verification/红舟过雨.mp4) · [逐秒抽帧](verification/film-frames.jpg)

| 测量项 | 本次结果 |
|---|---|
| 文字导演 | 当前 Agent Home 模型 `grok/grok-4.7-build-fast@500k`；图像和视频均由本地 GPU 处理。 |
| 两张关键帧 | Z-Image Turbo，640×352，各 8 步；服务端实际生成 16.01 / 16.68 秒。 |
| 两个动态镜头 | Wan2.2 TI2V-5B FP16，20 步，640×352，每镜 49 帧、12 fps。服务端实际生成 77.09 / 75.99 秒。 |
| 最终导出 | FFmpeg 合片 0.70 秒。H.264，960×540，24 fps，共 196 帧、8.17 秒。原始镜头无对白，AAC 立体声音轨为空声。画面放大和 12→24 fps 的帧重复均在导出阶段完成。 |
| 完整耗时 | 活跃执行累计 384.0 秒，含 GPU 排队与一次失败尝试。首次提交至成功 616.8 秒，含暂停排查及从检查点恢复的时间。 |
| 物理显存 | 标准版两个视频任务期间分别采样到 21,737 / 21,702 MiB 峰值，含同卡其他进程。 |

第一条全流程委托已独立从头到尾成功。以同一标准重新拍摄时，文字模型有一次把剧本 JSON 当作对话文本返回。现在 SDK 在同一会话明确要求重发工具调用，仍无有效工具回执时会显示失败。该项目重试保留了已写入的大纲，并成功完成后续制作。

另外，用一条自然语言指令要求把另一版成片的第二镜移到首位，入点设为 0.25 秒、时长裁成 3 秒，随后导出。Agent 实际执行了 `move_clip`、`trim_clip` 和 `export`，8.81 秒后得到 170 帧、7.08 秒的另一个文件。

独立的已建项目还验证了一条包含五个动作的导演委托。25.34 秒内，SDK 实际执行了新增大纲、章节和镜头、采用已有项目图片、移动 Map 节点。移动节点后原有剪辑顺序保持一致。

## 独立生图与局部修图

在没有任何章节或镜头的项目中生成一张橙色陶瓷杯的商品图，上传选区，要求把釉色改为钴蓝。工作台先让 Boogu 读取原图和遮罩，在模型潜空间内约束修改，最后合成原图分辨率的结果。[原图与修图对照](verification/independent-compare.jpg) · [编辑后 PNG](verification/杯子-局部修图.png)

| 测量项 | 本次结果 |
|---|---|
| 原图 | 640×448，Z-Image Turbo，8 步；服务端生成 16.32 秒。 |
| 局部修图 | Boogu Edit Turbo，原生工作尺寸 1216×864，交付 640×448；服务端生成 61.82 秒。 |
| 保护区 | 143,248 个黑色遮罩像素逐像素核对，改变 0 个。涂选区内改变 143,367 个像素，原中性背景区域的平均通道偏差 3.63/255。 |
| 归属 | 原图、遮罩和修订图均属于该独立项目。生成下载完成后仍有 0 章、0 个剪辑片段。 |

本次独立生图提交时，单卡正处理另一项目的视频，应用队列等待 123.87 秒，提交到完成共 140.31 秒。已列出的 16.32 秒为模型服务端执行时间。独立修图提交到完成为 63.11 秒。

先前一次试验只在模型生成整图后套上矩形选区，杯子形状与窗框产生可见错位。当前回归同时检查颜色变化、选区外像素和选区内中性背景的偏差；在本次固定试题上旧版偏差达到 62.74/255。

## 交互性能与回归

在 Apple Silicon 本机、Chrome 158.0.8127.37 的冷浏览器上下文下重复启动 30 次，服务器已预热。测试集为 100 项目、10 万个合成素材摘要，打开的工程含 10 章、500 镜和 5 万字。浏览器模拟 30 Mbps 链路与 50 ms 网络延迟。缩略图使用相同的合成图片内容和不同的资源地址。

| 指标 | p50 | p95 |
|---|---:|---:|
| 项目目录可操作 | 303.45 ms | 311.5 ms |
| 完整 Map 可操作 | 410.55 ms | 426.4 ms |
| 平移与缩放时的帧间隔 | 16.7 ms | 16.7 ms |
| 逐字输入至第二次绘制 | 24.3 ms | 32 ms |

连续输入 500 字保存并刷新后，内容完整。浏览器回归还覆盖三种主题切换、持久化、遮罩原图尺寸、项目隔离、丢失服务应答后幂等重试和移动端导航。[主题对比](verification/themes.jpg) · [机器可读指标](verification/measurements.json)

同一灯具首帧、提示、种子及 25 帧尺寸下，标准 20 步 FP16 用时 65.05 秒，快速 8 步用时 53.53 秒。快速版后段引入了提示之外的手臂与杂色；标准版保住灯具轮廓，现设为默认。视频核心指标来自单机少量样本，不能据此承诺不同题材的画质、并发能力或长片交付时间。[快速与标准档对照](verification/wan-comparison.png)
